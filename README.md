# 習慣カウンター（habit-counter）

**リセットしない、減らすための習慣カウンター。**

減らしたい習慣を記録して、「どのくらい減らせたか」「いつ多いのか」を見える化し、自分なりの対策を考えるためのWebアプリです。

**公開URL**：https://admon-networks.github.io/habit-counter/

## なぜ作ったのか

禁煙アプリをいくつか試しましたが、どれも「1本吸ったら記録がリセットされる」だけで、自分には合いませんでした。

知りたかったのは、

- 前と比べてどのくらい減らせているのか
- 今月どのくらい吸っていて、いくら使っているのか
- どんな時間帯や場面で多いのか

という、**減らすための作戦を立てる材料**でした。

完全にやめることだけをゴールにすると、1回でも失敗した時点で記録が意味を失ってしまいます。このアプリでは、記録した1回1回をリセットせずに残し、それを材料にして少しずつ減らしていくことを目指しています。

## 大事にしていること

- **リセットしない**：記録は失敗ではなく、対策を考えるためのデータ
- **責めない**：数字は「評価」ではなく「材料」として見せる
- **データは手元に**：記録は自分の端末の中だけに保存し、外部には送らない

## 主な機能

- `+1` ボタンで記録、`-1` ボタンで直前の記録を取り消し（今日の記録のみ）
- 今日の回数、今月の回数・金額を表示
- 1日あたりのペースから、今月末の金額を予測
- 1回あたりの金額を設定（例：1箱600円・20本なら30円）
- アプリに戻ってきたときに表示を自動更新（日付をまたいでも正しく表示）

## 使い方

1. iPhoneのSafariで公開URLを開く
2. 共有ボタン →「ホーム画面に追加」
3. 「1回あたりの金額」を入力して使い始める

## データの保存について

記録は**利用している端末のブラウザ内（localStorage）にのみ保存**されます。サーバーには送信されないため、他の人に見られることはありません。

その代わり、次の点に注意してください。

- ホーム画面のアプリを削除したり、ブラウザのデータを消去したりすると記録も消えます
- 別の端末とは記録が共有されません

## 使用技術

- HTML / CSS / JavaScript（フレームワーク・ライブラリなし）
- localStorage（データ保存）
- GitHub Pages（ホスティング）

## 設計メモ

### 回数ではなく「記録した時刻」を保存している

保存しているのは回数ではなく、ボタンを押した時刻（ISO 8601形式）の一覧です。

```json
["2026-10-11T13:30:00.000Z", "2026-10-11T15:12:45.000Z"]
```

時刻の一覧を持っておけば、「今日は何回」「今月は何回」をあとから自由に計算できます。日付が変わったときのリセット処理も不要で、「どのくらい減らせたか」「何時ごろに多いか」といった分析にもそのまま使えます。リセットしないというコンセプトを、データの持ち方でも支えています。

### 月末予測の計算方法

```
1日あたりのペース ＝ 今月の金額 ÷ 数え始めから今日までの日数
月末の予測       ＝ 1日あたりのペース × 今月の記録対象の日数
```

使い始めた月は、最初の記録の日を数え始めの日として扱います（1日から数えると、使い始める前の日が「0回の日」として計算され、予測が低く出てしまうため）。

### 特定の習慣に限定しない作りにしている

もとはタバコの本数を減らす目的で作りましたが、「回数 × 単価」で考えられる習慣（コーヒー、コンビニ、お酒など）にも使えるよう、特定の用途に絞らない設計にしています。今後、複数の習慣を切り替えて記録できるようにする予定です。

## ローカルでの動作確認

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8000/` を開きます。
